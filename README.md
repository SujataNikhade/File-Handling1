# File-Handling1
File Handling Programs in Python

This repository contains a set of Python scripts focused on learning and practicing file handling operations. Each script performs a specific task related to reading, writing, updating, and analyzing text files.

## Contents

The programs include the following operations:

Creating and writing files

Reading file content in different ways

Copying content from one file to another

Finding and replacing words inside a file

Removing blank or unnecessary lines

Transposing file data (row ↔ column)

Generating multiple files automatically

Counting vowels, consonants, digits, and special characters

Counting words and their frequency

Reading a file from bottom to top

Detecting the largest and smallest word

Masking email addresses using regular expressions

Character mapping (letters → *, digits → #, others → -)

## Objective

The main purpose of this project is to strengthen knowledge of:

File input/output (I/O)

Text processing

String functions

Regex usage

Basic data processing techniques

This practice will help in automation tasks, data analysis, and backend logic building.
